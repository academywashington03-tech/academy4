# تقرير فحص ما قبل النشر — Washington Academy

**تاريخ الفحص الفعلي:** 15 أكتوبر 2026  
**الحالة:** تم فحص الحزمة محلياً فقط. لم يتم إنشاء حسابات خارجية أو قاعدة بيانات أو نشر الموقع.

## ما تمت مراجعته
- جرد محتويات ZIP (270 مساراً/مدخلاً)، ومراجعة دليل النشر العربي `docs/00-publish-beginner-ar.md`.
- إعدادات Next.js و`package.json` وTypeScript وGitHub Actions و`.gitignore` و`.env.example`.
- ملفات ترحيل SQL من `0001` إلى `0011` وملفات اختبارات SQL، واختبارات التطبيق، وملفات إعداد Paymob ذات الصلة.
- فحص آلي لأنماط شائعة لمفاتيح خاصة ومفاتيح JWT/خدمة/دفع. لم يظهر دليل على مفتاح حقيقي ضمن الأنماط المفحوصة. هذا فحص محدود وليس ضماناً مطلقاً. لم تُعرض أي قيم سرية.
- لم يوجد `.env` أو `.env.local` أو ملف بيئة إنتاجي في الحزمة. `.gitignore` يستثني ملفات البيئة الفعلية والمفاتيح والنسخ الاحتياطية.

## التعديلات الآمنة
- حُذف `tsconfig.tsbuildinfo` لأنه ملف كاش تولّده TypeScript وليس مصدراً مطلوباً للنشر.
- لم تُغيّر صفحات الموقع أو التصميم أو منطق الدفع أو قاعدة البيانات.
- لم أُنشئ `package-lock.json` اصطناعياً: محاولة `npm install` انتهت بمهلة، ولا يوجد ملف قفل في الحزمة الأصلية. يلزم إنشاؤه بتثبيت ناجح على جهاز متصل بالإنترنت قبل الاعتماد على بناء قابل لإعادة الإنتاج.

## نتائج تشغيل فعلية في بيئة الفحص
| الفحص | النتيجة |
|---|---|
| `npm test` | **نجح: 85 اختباراً، 0 فشل** باستخدام Node.js 22.16.0 وأمر `node --experimental-strip-types --test tests/*.test.ts` |
| `npm install --ignore-scripts --no-audit --no-fund` | **لم يكتمل**؛ انتهت مهلة بيئة الفحص |
| `npm run typecheck` | لم يُشغّل في هذه الجولة؛ لا تتوفر الحزم اللازمة |
| `npm run lint` | لم يُشغّل في هذه الجولة؛ لا تتوفر الحزم اللازمة |
| `npm run build` | لم يُشغّل في هذه الجولة؛ لا تتوفر الحزم اللازمة |
| اختبارات SQL / Supabase | لم تُشغّل؛ لا توجد قاعدة بيانات تجريبية متصلة |
| Playwright / E2E | لم يُشغّل |
| دفع Paymob | لم تُنفّذ أي عملية دفع فعلية أو تجريبية |
| نشر عام والتحقق من الرابط | لم يحدث؛ لا يوجد رابط منشور يمكن تأكيده |

## المطلوب قبل النشر
1. استخدم Node.js 22.18 أو أحدث ضمن الإصدار 22، وفق `.nvmrc` و`engines`.
2. على جهاز متصل بالإنترنت داخل مجلد المشروع، نفّذ `npm install` وانتظر نجاحه؛ أضف `package-lock.json` الناتج إلى المستودع.
3. شغّل بالترتيب: `npm run typecheck` ثم `npm test` ثم `npm run lint` ثم `npm run build`. لا تعتبر الموقع جاهزاً للإطلاق إذا فشل أحدها.
4. طبّق ملفات SQL من `0001` إلى `0011` بالترتيب في مشروع Supabase جديد، وتوقف عند أول خطأ. نفّذ اختبارات SQL على مشروع تجريبي منفصل فقط، وليس قاعدة الإنتاج.
5. أضف مفاتيح Supabase الحقيقية في إعدادات استضافة الخادم فقط. لا تضع `SUPABASE_SERVICE_ROLE_KEY` أو مفاتيح Paymob السرية في GitHub أو في متغيرات `NEXT_PUBLIC_*`.
6. الدفع الإلكتروني غير جاهز حتى تضبط Paymob بمفاتيح الاختبار وتنجح عملية اختبار فعلية والتحقق من الإشعار. الدفع اليدوي لا يثبت عمل Paymob.
7. لم يُنشر الموقع في هذه المراجعة؛ يلزم حساب GitHub وSupabase وVercel وإتمام خطوات الدليل العربي. خطة Vercel المجانية مخصصة للاستخدام الشخصي غير التجاري وفق الدليل؛ تحقّق من شروط الخطط الحالية قبل إطلاق أكاديمية مدفوعة.
